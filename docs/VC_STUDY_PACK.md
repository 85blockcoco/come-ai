## 1. FICHES PAR CHAPITRE

### 1.1 Topic 1 — VC & écosystème
- **Définition VC** : investissement minoritaire dans startups early-stage, sous incertitude, visant la croissance rapide.
- **Stratégies PE** : VC (minority/early), growth equity (minority/mature), buyout (majority), alternative (distressed, real assets).
- **Startup** : innovation, scalabilité, high risk/high reward, resource-constrained, itératif (PMF).
- **VC distinct** : power law ; 90–95% échouent le plan, 70–80% le return ; 20–40+ startups/fonds ; staged financing ; preferred equity.
- **Equity par round** : Pre-seed 5–15%, Seed 15–30%, A 20–30%, B 15–25%, C 10–20%.
- **IRR requis** : Seed 40–70%, A 35–50%, B 30–40%, C 25–35%.
- **Founders** : <50% en Series B, 20–30% à l'exit.
- **Gouvernance** : board, veto, mentoring.

### 1.2 Topic 2 — Évaluation
- **Opportunité** : marché (taille, croissance, lifecycle), concurrence, barrières, timing.
- **Équipe** : complémentarité, expérience, vision, motivation.
- **Produit/tech** : PMF, différenciation, scalabilité.
- **Business model** : unit economics, CAC/LTV, marges.
- **Plan financier** : projections, hypothèses, scénarios, milestones.
- **Due diligence** : commercial, technique, juridique, financier, RH.
- **Processus** : screening → évaluation → DD → négociation → comité → closing.

### 1.3 Topic 3 — Valorisation, ownership, returns
- **Formules** : Post = Pre + Inv ; Ownership VC = Inv/Post ; Prix/action = Pre/shares ; MOIC = sortie/capital ; IRR = VAN=0.
- **Dilution** : new = old × (1 − part cédée).
- **Cap table** : évolution ownership par round.
- **Option pool** : pré/post-money.
- **Anti-dilution** : weighted average vs full ratchet.
- **Liquidation pref** : 1x, participating, non-participating, capped.
- **Down round** : ratchet, pay-to-play, cram-down.
- **Returns** : MOIC cibles par stage ; power law.

### 1.4 Topic 4 — Term sheets
- **Clauses** : valuation, liquidation pref, participation, cap, anti-dilution, vesting (cliff, accélération), board, veto, drag/tag, ROFR, co-sale, redemption, pay-to-play, conversion, dividends.
- **Convertibles & SAFE** : cap, discount, intérêt, maturity, MFN.
- **Négociation** : trade-offs, alignement.

### 1.5 Topic 5 — Gouvernance, monitoring, exits
- **Gouvernance** : board, veto, reporting, information rights.
- **Monitoring** : KPIs, milestones, reporting.
- **Exits** : M&A, IPO, secondary, buyback, write-off ; timing ; waterfall.
- **Zombie companies**, down rounds.

## 7. APPROFONDISSEMENT — NOTIONS AVANCÉES

### 7.1 Valorisation — Méthodes
- **VC Method** : post-money = investissement / ownership cible ; pre-money = post − invest.
- **DCF** : projection cash flows, actualisation au coût du capital (taux VC élevé).
- **Multiples** : EV/Revenue, EV/EBITDA selon stage/secteur.
- **Scorecard / Berkus** : valorisation pré-revenue par facteurs.
- **Risk factor summation** : ajustement par risques.

### 7.2 Cap table — Exemple complet
Round 0 : founders 100% (1M shares).
Seed : invest 0.5M pour 20% → post 2.5M, prix 0.25/share, nouvelles shares 2M. Founders 80%.
Series A : pre 8M, invest 2M → post 10M, prix 1€/share, nouvelles shares 2M. Founders 80%×(10/12)? calcul détaillé.
Series B down round : anti-dilution weighted average.

### 7.3 Waterfall numérique
Sortie 30M. VC A : 5M investi, 1x non-participating pref. VC B : 3M, 1x participating, cap 3x.
Étape 1 : rembourser prefs (5+3=8M). Reste 22M.
Étape 2 : participation VC B sur reste selon ownership. Puis cap.

### 7.4 Term sheet — Clauses avancées
- **Participating preferred avec cap** : pref + part pro-rata jusqu'au cap.
- **Full ratchet** : prix ramené au plus bas round.
- **Weighted average** : prix ajusté par nb shares.
- **Pay-to-play** : perd les prefs si ne suit pas le round.
- **Cram-down** : dilution forcée des non-participants.
- **Vesting accélération** : single trigger (change of control), double trigger (change + termination).
- **Protective provisions** : veto sur fusion, dette, changement de stratégie.

### 7.5 Gouvernance — Détails
- Board seats : typiquement founder + VC + indépendant.
- Information rights : reporting mensuel, audit annuel.
- Veto sur : fusion/acquisition, dette > seuil, changement de business, émission d'actions.

### 7.6 Exits — Détails
- **IPO** : lock-up, sous-performance post-IPO.
- **M&A** : synergies, earn-out, escrow.
- **Secondary** : vente de parts entre investisseurs.
- **Write-off** : faillite, liquidation.

## 11. GLOSSAIRE COMPLET
- **Pre-money** : valorisation avant investissement.
- **Post-money** : valorisation après investissement.
- **MOIC** : Multiple on Invested Capital.
- **IRR** : Internal Rate of Return.
- **Cap table** : tableau de capitalisation.
- **Term sheet** : accord de principe.
- **Liquidation preference** : priorité de remboursement.
- **Anti-dilution** : protection contre la dilution.
- **Vesting** : acquisition progressive des actions.
- **Cliff** : période minimale avant déblocage.
- **Drag-along** : obligation de suivre la vente.
- **Tag-along** : droit de suivre la vente.
- **ROFR** : droit de préemption.
- **SAFE** : Simple Agreement for Future Equity.
- **Convertible note** : dette convertible.
- **Down round** : round à valorisation inférieure.
- **Pay-to-play** : obligation de suivre.
- **Cram-down** : dilution forcée.
- **Power law** : distribution à queue lourde.
- **PMF** : Product-Market Fit.
- **Unit economics** : économie unitaire (CAC/LTV).

- Da Rin & Hellmann (2020), Zeisberger et al. (2025), Gompers et al. (2020), Cassar (2009), Puri & Zarutskie (2012), EVCA/OECD/Startup Genome.
