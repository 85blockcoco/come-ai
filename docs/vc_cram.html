Formula sheet

1. Valuation and ownership VC04

  • Post-moneyV_POST = I / F_INVThe investment I buys the fraction F_INV of the post-money company.
  • Pre-moneyV_PRE = V_POST - IThe investment changes the post-money value, never the negotiated pre-money value.
  • Share priceP = V_PRE / S_PRES_PRE is the number of shares before the round (fully diluted if the pool is pre-money).
  • New sharesS_INV = I / PThe investor receives shares at the negotiated price.
  • Investor fractionF_INV = S_INV / (S_PRE + S_INV) = I / V_POSTEquivalent formulations; use the one that matches the data given.
  • Founder dilutionF_FOUNDER,post = F_FOUNDER,pre x (1 - F_INV)Multiply by (1 - F_new) for every later round.

2. Cap table and option pool VC05

  • Post-money shares with a poolS_TOTAL = S_FOUNDERS / (1 - F_INV - F_POOL)The pool is usually created before the investment, so it dilutes the founders, not the new investor.
  • Pool sharesS_POOL = F_POOL x S_TOTALUse the post-money pool percentage stated in the term sheet.
  • Investor sharesS_INV = F_INV x S_TOTALCheck: founders + pool + investor = total.
  • Fully dilutedS_FD = common + options + warrants + convertiblesEvery security that can become common stock is counted.

3. VC method and multi-round ownership VC09

  • Capital cash multipleCCM = (1 + h)^th is the hurdle rate, t the years to exit.
  • Post-money from exitV_POST = V_EXIT / CCMDiscount the expected exit value back at the hurdle rate.
  • Required ownershipF_INV = I / V_POST = I x (1 + h)^t / V_EXITThis is the core VC-method formula.
  • Exit ownershipF_exit = F_post x (1 - F_next) x (1 - F_next2) ...A round is diluted by every subsequent round, not by earlier ones.
  • Target-multiple ladderV_POST,last = V_EXIT / m_last; V_PRE,i = V_POST,i - I_i; V_POST,i-1 = V_PRE,i / m_i-1Work backwards from the exit when the case gives a target multiple per round.
  • Exit proceedsProceeds = F_exit x V_EXITThe multiple achieved is proceeds divided by the investment in that round.

4. Term sheet economics and control VC06

  • Non-participating preferencePayoff = max(LP, F x V_EXIT)The investor converts when conversion is worth more than the preference.
  • Conversion thresholdV* = LP / FAbove V*, a non-participating investor converts.
  • Participating preferencePayoff = LP + F x (V_EXIT - LP), cappedThe cap is usually a multiple of LP; compare with conversion and take the maximum.
  • Participating cap thresholdV** = cap / FAbove V**, even a participating investor prefers to convert.
  • Broad-based weighted averageCP2 = CP1 x (A + B) / (A + C)A = shares before the round, B = new money / CP1, C = new shares actually issued.
  • Full ratchetCP2 = new issue priceThe harshest anti-dilution: the conversion price drops to the new round price.
  • Reverse vestingVested = shares x min(1, months / total months), after the cliffA 4-year monthly vesting with a 1-year cliff vests 25% at month 12.

5. Convertible notes and SAFEs VC16

  • Discount priceP_discount = P_new x (1 - discount)A 20% discount means the note pays 80% of the round price.
  • Cap priceP_cap = cap / fully diluted pre-money sharesThe cap is a maximum valuation, not a maximum price.
  • Conversion priceP_convert = min(P_discount, P_cap)The investor gets the better of the two protections.
  • Shares issuedS_note = amount / P_convertInterest and maturity add to the amount if the note is not converted earlier.

6. LBO, returns and attribution VC13

  • Entry / exit EVEV = multiple x EBITDAUse LTM EBITDA at entry and exit-year EBITDA at exit.
  • Equity valueEquity = EV - net debtNet debt = debt - cash.
  • CFADSCFADS = EBITDA - capex - change in NWC - taxesCash flow available for debt service.
  • Free cash flowFCF = CFADS - interestWith a cash sweep, debt falls by FCF each year.
  • Debt scheduleDebt_t = Debt_(t-1) - FCF_tInterest is computed on the opening debt balance.
  • Cash-on-cash multipleCCM = exit equity / entry equityUse the sponsor's share if management rolls over equity.
  • IRRIRR = CCM^(1/t) - 1Do not divide CCM by t; take the t-th root.
  • Return attributionEBITDA impact = ΔEBITDA x entry multiple; multiple impact = Δmultiple x exit EBITDA; net-debt impact = entry debt - exit debtThe three effects sum to the equity return.

7. Fund economics and performance VC02

  • Management feeFee = committed capital x fee %Often 2% of commitments during the investment period.
  • Carried interestCarry = 20% x profits above the hurdleThe hurdle is usually 8%; the catch-up restores the 80/20 split.
  • TVPITVPI = (distributions + NAV) / paid-in capitalTotal value divided by capital called.
  • DPI / RVPIDPI = distributions / paid-in; RVPI = NAV / paid-inDPI is cash returned; RVPI is unrealized value.
  • J-curveEarly negative returns, later positiveCaused by fees, write-downs and the timing of exits.

The 14 traps that cost marks

  1. Pre-money vs post-money → V_POST = V_PRE + I. The investment amount affects the post-money value; the pre-money is negotiated separately.
  2. Option pool → The pool is usually pre-money. It dilutes founders and earlier holders, not the new investor.
  3. Fully diluted → Count options, warrants and convertibles. A percentage of the cap table that ignores the pool is not fully diluted.
  4. Liquidation preference → It is a floor, not a guarantee. If the exit is below the preference, the investor receives the available proceeds, not the full LP.
  5. Conversion → Take the maximum of preference and conversion. A non-participating investor converts only when F x exit > LP.
  6. Participating preferred → Apply the cap before comparing with conversion. The cap is a multiple of the preference, not of the investment.
  7. Anti-dilution → Broad-based weighted average is softer than full ratchet. Full ratchet resets the price to the new issue price; weighted average blends.
  8. Convertible note → Use the lower of discount price and cap price. The two protections are not added; the investor takes the better one.
  9. IRR → IRR = CCM^(1/t) - 1. Dividing the multiple by the holding period is the most common exam error.
  10. Multi-round ownership → Dilute by every later round. Do not apply later dilution to earlier rounds twice, and do not forget it either.
  11. LBO debt → Interest is on the opening balance. With a cash sweep, the balance falls each year, so interest falls too.
  12. Return attribution → Use the entry multiple for EBITDA, the exit EBITDA for the multiple effect. The three effects must sum to the equity return.
  13. Enterprise value → EV = equity + debt - cash. Issuing equity to repay debt leaves EV unchanged.
  14. Strategic vs financial buyer → Synergies and horizon explain the premium. A financial buyer cannot pay for synergies it does not have.

Q162 pts · VC02

What are the steps of capital allocation in a distribution waterfall?

Show solution

Answer: 1) Return contributed capital to LPs. 2) Pay the preferred return/hurdle (about 8%). 3) GP catch-up until the GP has 20% of profits. 4) Split the remainder 80/20 between LPs and GP. 5) Clawback if the GP was overpaid.

Worked solution: The standard European waterfall is deal-by-deal or fund-wide: capital, hurdle, catch-up, 80/20 carry, then a clawback/true-up at the end.

Q172 pts · VC16

In seed investing, what are convertible notes and when/why are they used?

Show solution

Answer: Short-term debt-like instruments that convert into preferred shares at the next priced round, usually with a discount (10-20%) and/or a valuation cap. They avoid pricing an immature startup, are fast and cheap, and give the investor downside protection and control rights. Typical maturity is 12-24 months.

Worked solution: Key points: no valuation at issuance, conversion at a discount/cap, maturity and interest, speed and standardisation, and the tension between founder and investor incentives if the next round is delayed.

Q182 pts · VC03

Growth-equity funds target firms with high capex and working-capital needs. What are the three main types of target firms?

Show solution

Answer: Mature SMEs; late-stage VC-backed firms/startups; corporate spin-offs/carve-outs.

Worked solution: Growth equity sits between VC and buyout: minority stakes, proven business models, capital for scaling rather than survival.

Q192 pts · VC13

Explain rollover equity. Is it a positive or a negative sign?

Show solution

Answer: Equity that key pre-buyout shareholders (management, sometimes the seller) reinvest into the post-buyout company instead of cashing out. It is generally positive: it aligns management with the PE owner and signals the seller's continued belief; it also reduces the PE equity cheque. It can be negative if the seller wanted a full exit or if the fit with the PE is poor.

Worked solution: Mention alignment, signalling and financing benefits; also mention the seller's liquidity preference and potential conflicts.

Q202 pts · VC13

When would a sell-side M&A advisor recommend a broad auction?

Show solution

Answer: When maximizing competition and price is the priority: a broad auction reaches many strategic and financial buyers, limits any single buyer's bargaining power and helps the board meet its fiduciary duty. Costs: heavy preparation, confidentiality risk, business disruption and 'taint' if the auction fails.

Worked solution: Contrast with a targeted process: a broad auction maximizes price but is noisy; a targeted process protects confidentiality and is better when the buyer set is narrow.

Q2115 pts · VC04

Epäkunnossa Partners considers two startups. Both need €2m and would exit at €20m after two years if successful. Häviäjä: 10% success probability; Voittaja: 30%. Each founder has €3m expected lifetime income. The fund does not observe the founders' beliefs and assumes 20% success for both. It offers €2m at an €8m post-money with a 10% annual dividend and a 1.3x liquidation preference.

2023-C16a. What is each startup's expected exit value under the founder's belief? Is it worth investing (scrap value 0)?

2023-C16b. What ownership fraction and preferred terms does the offer imply? What is the conversion threshold?

2023-C16c. On success, what are the payoffs for the VC and the founders?

2023-C16d. Would each founder accept, given €3m lifetime income? Does the term sheet screen out the weaker startup?

Show solution

2023-C16a. What is each startup's expected exit value under the founder's belief? Is it worth investing (scrap value 0)?

Answer: Häviäjä: 10% × €20m = €2m (indifferent, not worth it after any hurdle). Voittaja: 30% × €20m = €6m (worth it).

Worked solution: Expected exit value = probability × exit value: €2m vs €6m. Against a €2m investment, Häviäjä barely breaks even; Voittaja has a positive expected payoff.

2023-C16b. What ownership fraction and preferred terms does the offer imply? What is the conversion threshold?

Answer: Ownership = 2/8 = 25%. Preferred value = 2×1.3 + 2×10%×2 = €3.0m. Conversion threshold = 3.0/0.25 = €12m.

Worked solution: Preferred terms: 1.3× liquidation preference (€2.6m) plus two years of 10% dividends (€0.4m) = €3.0m. The VC converts when 25% of exit exceeds €3m, i.e. above €12m.

2023-C16c. On success, what are the payoffs for the VC and the founders?

Answer: Exit €20m > €12m threshold, so the VC converts: VC = 25% × €20m = €5m; founders = €15m.

Worked solution: Because conversion beats the preference (€5m > €3m), the VC converts. Founders keep the residual €15m.

2023-C16d. Would each founder accept, given €3m lifetime income? Does the term sheet screen out the weaker startup?

Answer: Häviäjä: 10% × €15m = €1.5m < €3m → reject. Voittaja: 30% × €15m = €4.5m > €3m → accept. Yes, the contract screens out the low-quality startup.

Worked solution: The founder compares the expected payoff with the outside option (€3m). Only the high-type founder accepts, so the term sheet is a screening device.

Q2215 pts · VC13

Æble PE Partners buys Eple Co. at 8x LTM EBITDA and exits after three years at the same 8x. 50% debt at 10% with a cash sweep. LTM revenue $100m, growing 20% for two years; EBITDA margin 40%, flat; capex and depreciation 20% of revenue; no change in NWC; no tax for three years.

2023-C17a. Compute revenue, EBITDA, entry EV and exit EV ($m).

2023-C17b. Compute free cash flow and debt for each year ($m).

2023-C17c. Compute the exit equity value, cash return, CCM and IRR. Would you invest?

2023-C17d. Decompose the return into EBITDA, multiple and net-debt effects.

Show solution

2023-C17a. Compute revenue, EBITDA, entry EV and exit EV ($m).

Answer: Revenue 100 / 120 / 144 / 172.8; EBITDA 40 / 48 / 57.6 / 69.12; entry EV $320m; exit EV $552.96m.

Worked solution: Revenue grows 20%: 100, 120, 144, 172.8. EBITDA = 40% of revenue: 40, 48, 57.6, 69.12. EV = 8 × EBITDA: 320 entry, 552.96 exit.

2023-C17b. Compute free cash flow and debt for each year ($m).

Answer: CFADS 24.0 / 28.8 / 34.56; interest 16.0 / 15.2 / 13.84; FCF 8.0 / 13.6 / 20.72; debt 160 / 152 / 138.4 / 117.68.

Worked solution: CFADS = EBITDA - capex (20% of revenue), NWC change 0. Interest = 10% of opening debt. FCF = CFADS - interest. Debt falls by FCF each year (cash sweep).

2023-C17c. Compute the exit equity value, cash return, CCM and IRR. Would you invest?

Answer: Exit equity = 552.96 - 117.68 = $435.28m; entry equity = $160m; return = $275.28m; CCM = 2.72x; IRR = 39.6%; yes (above the ~20-25% LBO threshold).

Worked solution: Equity = EV - debt. CCM = 435.28/160 = 2.72x. IRR = 2.72^(1/3) - 1 = 39.6%. The deal clears the usual LBO hurdle.

2023-C17d. Decompose the return into EBITDA, multiple and net-debt effects.

Answer: EBITDA: (69.12-40)×8 = $232.96m (84.6%); multiple: 0 (same 8x); net debt: 160-117.68 = $42.32m (15.4%).

Worked solution: EBITDA impact = ΔEBITDA × entry multiple. Multiple impact = (exit multiple - entry multiple) × exit EBITDA = 0. Net-debt impact = entry debt - exit debt. The three sum to the $275.28m return.

Last-minute checklist

  • Pre-money vs post-money: the investment changes post-money only.
  • Option pool is pre-money; founders absorb it.
  • Liquidation preference vs conversion; participating cap.
  • Anti-dilution: weighted average vs full ratchet.
  • Convertible note: lower of discount price and cap price.
  • IRR: take the t-th root, never divide by t.
  • Multi-round: dilute by every later round.
  • LBO: interest on opening debt; debt falls by FCF.
  • Return attribution must sum to the equity return.
  • Write the formula, the numbers, the unit, then the sentence.
